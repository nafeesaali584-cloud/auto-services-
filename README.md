# UAE Auto Garage - Luxury Car Repair & Service Website

A modern, high-converting React application for luxury automotive repair and maintenance facilities in the UAE (Dubai, Sharjah, Abu Dhabi).

## Features
- **Responsive Architecture**: Built with React 18, Vite, and Tailwind CSS.
- **Conversion-Optimized**: Multi-step booking funnel, quote requests, and instant WhatsApp chat integration.
- **UAE Climate & Regulation Insights**: Dedicated climate advisories, warranty law disclosures, and dealership comparison matrices.
- **SEO Ready**: Schema.org LocalBusiness structured data, OpenGraph tags, and clean semantic markup.
- **Standalone Production Build**: Configured for instant deployment to Hostinger, cPanel, Vercel, or Apache servers with SPA routing.

## Development

```bash
npm install
npm run dev
```

## Production Build & Subdomain Packaging

To compile and package the deployment zip for Hostinger:

```bash
npm run package
```

This generates `subdomain_deploy.zip` containing the compiled assets and `.htaccess` ready to upload to your Hostinger File Manager.
